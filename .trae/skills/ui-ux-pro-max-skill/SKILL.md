# UI/UX Pro Max Skill

本技能用于对前端界面进行系统性 UI/UX 优化与设计审查，聚焦视觉层级、排版网格、移动端适配、可读性与交互动效，并给出可直接落地的代码修改建议（含 Tailwind 类与组件结构重构）。

## 何时调用
- 用户提出“优化页面外观”“移动端适配”“视觉更好看”“label 向下移动一点”等 UI/UX 相关需求时
- 重构样式体系、统一间距/字号/颜色、改善交互动效与无障碍体验时

## 输入
- 目标文件路径或代码片段（React/Tailwind/Vite 项目）
- 期望风格与设计意图（如：暗色玻璃拟态、轻动效、可读性优先）
- 约束（不得新增依赖、保持中文文案、移动端优先）

## 输出
- 可直接应用的代码补丁建议（className/Tailwind 变量/组件结构）
- 视觉与交互说明（为何这样修改，如何提升可读性与层级）
- 响应式与无障碍建议（断点策略、触控友好、对比度/键盘可达）

## 操作准则
- 遵循移动端优先与流式布局；优先使用现有 Tailwind 设计系统
- 统一间距与字号刻度（如 4/8/12/16），避免随意值
- 合理使用颜色与渐变，控制对比与层级，避免过度动效
- 保持中文文案一致性与专业语气，不引入英文
- 不新增库依赖；尽量编辑现有文件与组件

## 示例任务
- 精炼标签与控件的对齐方式：微调 margin/padding/line-height，使表单更规整
- 优化“label 向下移动一点”：通过栅格/间距系统制定稳定的垂直节奏
- 提升移动端体验：触控范围、滚动区域、底部导航安全距离

## 使用步骤
1. 指定待优化的组件或页面文件
2. 说明目标风格与需求（如“向下移动 label 4px，保持行间距不变”）
3. 输出包含修改原因与可应用补丁的建议
4. 验证在本地预览中实现预期效果
